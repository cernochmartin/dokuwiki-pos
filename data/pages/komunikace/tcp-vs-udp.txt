====== TCP vs UDP ======

==== TCP (Transmission Control Protocol) ====

| Vlastnost | Hodnota |
| Přenos | Spojovaný (connection-oriented) |
| Spolehlivost | Ano - potvrzování (ACK), znovuodeslání ztracených segmentů |
| Řazení | Ano - segmenty jsou doručeny ve správném pořadí |
| Rychlost | Nižší (kvůli režii) |
| Režie | Větší hlavička (20-60 B) |
| Řízení toku | Ano (okno, window size) |
| Řízení zahlcení | Ano (slow start, congestion avoidance) |
| Použití | Web, e-mail, FTP, SSH, databáze |

===== Princip spojení =====

**Three-way handshake** (navázání spojení):
  1. Klient → Server: **SYN** (seq=x)
  2. Server → Klient: **SYN-ACK** (seq=y, ack=x+1)
  3. Klient → Server: **ACK** (seq=x+1, ack=y+1)

**Ukončení spojení** (Four-way handshake):
  1. Klient → Server: **FIN**
  2. Server → Klient: **ACK**
  3. Server → Klient: **FIN**
  4. Klient → Server: **ACK**

===== Řízení toku =====

  * **Window Size** - kolik bajtů může odesílatel poslat bez potvrzení
  * **Sliding Window** - dynamicky se měnící okno
  * **Slow Start** - pomalý start, exponenciální růst okna

==== UDP (User Datagram Protocol) ====

| Vlastnost | Hodnota |
| Přenos | Nespojovaný (connectionless) |
| Spolehlivost | Ne - žádné potvrzování |
| Řazení | Ne - datagramy mohou dorazit v jiném pořadí |
| Rychlost | Vyšší (minimální režie) |
| Režie | Malá hlavička (8 B) |
| Řízení toku | Ne |
| Použití | DNS, DHCP, VoIP, streaming, online hry, NTP |

===== Hlavička UDP =====

| Pole | Velikost |
| Zdrojový port | 16 bitů (2 B) |
| Cílový port | 16 bitů (2 B) |
| Délka (Length) | 16 bitů (2 B) |
| Kontrolní součet (Checksum) | 16 bitů (2 B) |

==== Srovnání ====

^ Vlastnost ^ TCP ^ UDP ^
| Spojovaný | Ano | Ne |
| Spolehlivý | Ano | Ne |
| Zachování pořadí | Ano | Ne |
| Hlavička | 20-60 B | 8 B |
| Rychlost | Pomalejší | Rychlejší |
| Vhodný pro | Když záleží na datech | Když záleží na času |
| Příklady | HTTP, FTP, SMTP, SSH | DNS, DHCP, VoIP, IPTV |
